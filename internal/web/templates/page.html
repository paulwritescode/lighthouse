Data tools

Import, export, and manage your local database.

Import and export

Move a portable data set, or save a full SQLite snapshot.

Exports include stored results and active memory. PDF is a readable report; use a data format for round-trip imports.
Imports merge records into this database. A duplicate stable ID or memory key is skipped.

Storage and deletion

Even with no saved results or memory, SQLite uses disk space for its tables, indexes, and change history. The WAL is a journal of recent writes; its size can remain nonzero until SQLite checkpoints it.

Deleting removes the database and its journal, including results, memory, snapshots, and change history. Lighthouse then creates a small, empty database so the dashboard stays available. On macOS, the operating system asks for an administrator password; the website never receives it.
