# Lighthouse 0.2.0

**Release date:** 2026-11-09
**Status:** Local development release

## Highlights

- The overview shows the database file, active WAL, and combined live footprint.
- Metrics use a more compact ruled layout; native HTML and server-rendered pages remain the dashboard foundation.
- Runtime documentation now states directly that `lighthouse code` executes embedded Starlark inside the Go CLI. There is no Python subprocess, per-call script compilation, MCP transport, or separate Lighthouse execution charge.
- README and architecture notes describe the local setup, provider-token boundary, database import behavior, and current sandbox limits.

## Upgrade and compatibility

The SQLite schema is unchanged. Keep a backup before upgrading as usual. SQLite `.db` imports continue to merge artifacts and active memory into the current database; they do not replace the live file.

## Known limits

- The in-process Starlark runtime has no hard memory limit.
- Imported PDFs are retained as raw source data and are not text-extracted.
- Startup service installation and general-purpose semantic embedding are not included.
