# Lighthouse 0.3.0

**Release date:** 2026-11-09
**Status:** Local development release

## Highlights

- Install the CLI with `go install github.com/paulwritescode/lighthouse/cmd/lighthouse@v0.3.0`.
- Add the root package as a Go dependency with `go get github.com/paulwritescode/lighthouse@v0.3.0`; use `OpenDefault` to share the CLI database or `Open(path)` for another local SQLite file.
- Add dashboard selection of individual rows, all currently shown rows, or every matching record. Bulk result updates set project/kind/agent; bulk memory updates set project/kind. Batch deletes require confirmation.
- Bulk operations are per-item audited, with a 10,000-record cap and partial completion notices.

## Compatibility

The canonical Go module path is `github.com/paulwritescode/lighthouse`, matching the public GitHub repository. No SQLite schema migration was added. Bulk APIs use the existing application store and metadata JSON.

## Install

```sh
go install github.com/paulwritescode/lighthouse/cmd/lighthouse@v0.3.0
```

Then follow [the agent installation guide](../agent-integration.md) to set up Codex or Claude Code.
